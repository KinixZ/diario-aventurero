Ajustes del diario

personajes

Para pasarlos a otro dispositivo o a la web del grupo: exporta aquí e importa allá.

traducción al español

Los textos de 5etools vienen en inglés. El diario puede traducirlos y guardar cada traducción en este dispositivo para no repetirla.

Traducción fija

Archivos traduccion-*.json con los textos ya traducidos: se ven en español al instante, sin internet. Lo que no venga en el archivo usa el traductor de arriba.

servidor de campañas

Dirección del servidor donde viven las campañas. Si abriste el diario desde el servidor del proyecto no hace falta escribir nada.

estilo del diario
manual de monstruos

El archivo bestiario-5e.json con las criaturas de tu 5etools. El DM lo usa para meter enemigos al combate; los jugadores, para leer el Manual en el separador Bestiario. Se crea en la laptop con npm run bestiario.

biblioteca de 5etools

Carga los datos de tu copia de 5etools. Se guardan solo en este dispositivo y funcionan sin internet.

En el teléfono: si al tocar no se abre el selector, abre el diario en el navegador (Chrome o Safari) y cárgalo ahí. Si el archivo está en Drive o WhatsApp, guárdalo primero en Descargas.
